# Lotus 1-2-3 for VAX/VMS V1.0 (Lotus Development Corp.)

**Lotus 1-2-3 for VAX/VMS V1.0** is an authentic DEC VAX BASIC recreation of the official 3D spreadsheet developed by **Lotus Development Corporation (Cambridge, MA)** for DEC VAX/VMS and `ALL-IN-1` systems (1989–1994), featuring 3D multi-sheet worksheets (`A:A1..D:B4`), `@SUM`/`@NPV`/`@IRR`/`@STD` financial functions, `/Data Table` sensitivity analysis, and `.WK3` file persistence.
