# SAS Institute SAS System V6.06 for VAX/VMS

**SAS System V6.06** is an authentic DEC VAX BASIC recreation of the enterprise statistical analysis and data management system developed by **SAS Institute, Inc. (Cary, NC)** for DEC VAX/VMS systems (1984–1995), supporting `DATA` step observations, `PROC PRINT`, `PROC MEANS`, `PROC FREQ`, and `PROC REG` linear regression with `SASLIB.DAT` library persistence.
