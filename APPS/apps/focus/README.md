# Information Builders FOCUS V6.5 4GL & DBMS for VAX/VMS

**FOCUS V6.5** is an authentic DEC VAX BASIC recreation of the enterprise Fourth-Generation Language (4GL) and hierarchical/relational DBMS by **Information Builders, Inc. (New York, NY)** for DEC VAX/VMS systems, supporting `.MAS` Master File Descriptions (`MASTER`), `TABLE FILE` reporting (`TABLE`), `DEFINE FILE` virtual field calculations (`DEFINE`), `GRAPH FILE` histograms (`GRAPH`), and `MODIFY FILE` updates (`ADD`).
