# Evans Griffiths & Hart, Inc. (EG&H) KDSS V4.0 Key-to-Disk Subsystem

**EG&H KDSS V4.0** is an authentic DEC BASIC-PLUS-2 recreation of the high-speed multi-operator key-to-disk data entry and key-verification subsystem (`KDFMT`, `KDENT`, `KDVER`) authored by **Evans Griffiths & Hart, Inc. (Lexington, MA)** for DEC PDP-11 RSTS/E and VAX/VMS systems (1976–1989).
