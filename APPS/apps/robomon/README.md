# Heroix RoboMon V5.0 Rule-Based VAX/VMS Operations Manager

**Heroix RoboMon V5.0** is an authentic DEC VAX BASIC recreation of the automated rule-based system monitoring and corrective operations package authored by **Heroix Corporation (Newton, MA)** for DEC VAX/VMS systems, supporting VMS performance and queue rule definition (`RULES`), threshold violation detection (`EVALUATE`), and automated DCL corrective action dispatch (`AUTOCORRECT`).
