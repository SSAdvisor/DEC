# Comshare System W / Commander EIS — Multidimensional OLAP Decision Support System

**Comshare System W / Commander EIS** is an authentic DEC VAX BASIC recreation of the multidimensional OLAP financial hypercube (`System W`) and executive briefing board (`Commander EIS`) developed by **Comshare, Inc. (Ann Arbor, MI)** for DEC VAX/VMS systems (1982–1993), featuring cross-dimensional `ROTATE` views, multi-currency translation (`FXCONV`), and exception stoplight reporting (`BRIEFING`).
