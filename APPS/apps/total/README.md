# Cincom Systems TOTAL V8.0 Network Database Management System

**CINCOM TOTAL V8.0** is an authentic DEC BASIC-PLUS-2 recreation of the pioneering network-model Database Management System authored by **Cincom Systems, Inc. (Cincinnati, OH)** for DEC PDP-11 RSTS/E, RSX-11M, and VAX/VMS minicomputers (1974–1988).

## Features
- **Master Data Sets (`CUSTM`)**: Single-key direct randomized hash access (`READM`, `ADDM`).
- **Variable Entry Data Sets (`ORDERV`)**: Multi-record bidirectional chained linkage paths (`FINDX`, `READV`, `ADDV`).
- **DDL Schema Compiler (`DBGEN`)**: Compiles network database descriptors (`DBMOD`).
- **DML Console (`SINON`, `SINOF`, `READM`, `FINDX`, `ADDM`, `ADDV`)**: Status code `****` verification and `TOTMDB.DAT` persistence.
