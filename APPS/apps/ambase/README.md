# Amcor Computer Corp. AMBASE / AMWRITER / AMQUERY V4.2 DBMS

**AMBASE V4.2** is an authentic DEC BASIC-PLUS-2 recreation of the commercial RSTS/E relational/indexed database engine, `AMQUERY` query facility, `AMWRITER` report generator, and `AMGEN` VT100 screen builder authored by **Amcor Computer Corp. (Louisville, KY)** (1977–1989).
