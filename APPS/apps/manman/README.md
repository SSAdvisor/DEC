# ASK Computer Systems MANMAN V7.0 Manufacturing Management MRP II Suite

**ASK MANMAN V7.0** is an authentic DEC VAX BASIC recreation of the flagship commercial Manufacturing Resource Planning (`MRP II`) suite developed by **ASK Computer Systems, Inc. (Mountain View, CA)** for DEC VAX/VMS minicomputers (1980–1994), featuring `MANMAN/OMAR` (Manufacturing, Item Master, Multi-Level BOM & Time-Phased MRP Explosion), `CRP` (Work Center Routing & Capacity Requirements Planning), `MANMAN/OMAC` (Customer Order Management), and `MANMAN/GL` (Standard Cost Rollup).
