# WordPerfect 5.1 for VAX/VMS (WordPerfect Corp.)

**WordPerfect 5.1 for VAX/VMS** is an authentic DEC VAX BASIC recreation of the flagship multi-user word processor developed by **WordPerfect Corporation (Orem, UT)** for DEC VAX/VMS systems (1985–1994), featuring Reveal Codes (`Alt-F3`), the 115,000-word Speller (`WP{WP}US.LEX`), Thesaurus (`Alt-F1`), Mail-Merge (`Shift-F9`), and `.WPD` document persistence.
