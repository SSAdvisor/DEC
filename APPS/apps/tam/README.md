# Evans Griffiths & Hart, Inc. (EG&H) TAM V3.2 Terminal Application Manager

**EG&H TAM V3.2** is an authentic DEC BASIC-PLUS-2 recreation of the VT100 screen-painting, field-attribute validation, and transaction monitor authored by **Evans Griffiths & Hart, Inc. (Lexington, MA)** for DEC PDP-11 RSTS/E commercial applications (1978–1989).
