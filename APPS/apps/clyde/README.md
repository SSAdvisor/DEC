# Clyde Digital Systems CONTRL / AUDIT / LOCK (V4.1)

Terminal Session Monitor, Keystroke Audit Logger, and Intruder Lock utility suite for RSTS/E (`clyde`, `contrl`, `caudit`).

## Commands
- `SAMPLE` — Load 5 sample RSTS/E `KB:` terminal sessions
- `TERMINALS` / `LIST` — Display active `KB:` lines, privilege states, command counts, and risk scores
- `OBSERVE <kb>` / `CONTRL <kb>` — Live terminal session observation and keystroke mirror
- `AUDIT` / `CAUDIT` — Generate RSTS/E security audit log summary
- `LOCK <kb>` / `UNLOCK <kb>` — Freeze or release suspicious `KB:` lines
- `ADD`, `SAVE [file]`, `LOAD [file]`, `SHOW`, `CLEAR`, `HELP`, `EXIT`
