# Execucom IFPS/Plus V4.0 — Interactive Financial Planning System

**Execucom IFPS/Plus V4.0** is an authentic DEC VAX BASIC recreation of the non-procedural English corporate financial modeling language developed by **Execucom Systems Corporation (Austin, TX)** for DEC VAX/VMS systems (1979–1992), featuring natural-language equations, `SOLVE`, `WHAT IF` overrides, backward `GOAL SEEK`, and `MONTE CARLO` risk histograms.
