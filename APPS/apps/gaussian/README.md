# Gaussian 90 Ab Initio Quantum Chemistry System

**Gaussian 90** is an authentic DEC VAX BASIC recreation of the classic ab initio molecular orbital and quantum chemistry package authored by **Gaussian, Inc. (Pittsburgh, PA)** for DEC VAX/VMS systems, supporting Z-matrix molecular geometry specification (`ZMAT`), Restricted Hartree-Fock Self-Consistent Field convergence (`SCF`), Mulliken population & dipole analysis (`POP`), and harmonic vibrational IR frequency calculation (`FREQ`).
