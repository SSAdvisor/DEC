# Cognos PowerHouse 4GL V5.0 (PDL / QUICK / QUIZ / QTP) for VAX/VMS

**Cognos PowerHouse 4GL V5.0** is an authentic DEC VAX BASIC recreation of the #1 commercial VAX/VMS Fourth-Generation Language suite by **Cognos Incorporated (Ottawa, Ontario)**, featuring **PDL** (PowerHouse Dictionary Language), **QUICK** (VT220 screen design and validation), **QUIZ** (non-procedural report writer with control-break footings), and **QTP** (high-volume batch transaction processor).
