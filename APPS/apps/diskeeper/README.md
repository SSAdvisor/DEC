# Executive Software DISKEEPER V4.0 Online Disk Defragmenter for VAX/VMS

**DISKEEPER V4.0** is an authentic DEC VAX BASIC recreation of the classic online ODS-2 disk defragmentation and free-space consolidation utility authored by **Executive Software, Inc. (Glendale, CA)** for DEC VAX/VMS systems, supporting `INDEXF.SYS` & `BITMAP.SYS` fragmentation analysis (`ANALYZE`), online extent consolidation (`DEFRAG`), and LBN volume allocation mapping (`MAP`).
