# Saturn-WP V4.2 (Saturn Systems, Inc.)

**Saturn-WP** was the word processing component of the **Saturn Office Automation Suite** (`Saturn-WP`, `Saturn-Calc`, `Saturn-Base`, `Saturn-Graph`) for **DEC PDP-11 RSTS/E** (and RSX-11M / VAX/VMS), developed by **Saturn Systems, Inc.** of Minneapolis, Minnesota.

## Key Capabilities
- **Document Library (`DIR`, `SELECT`, `CREATE`, `READ`, `COPY`, `DELETE`, `PURGE`)**: Manages documents in `SATWP.DAT` across `REPORT`, `LETTER`, `MEMO`, and `WASTEBASKET` categories.
- **Live `Saturn-Calc` Spreadsheet Integration (`CALCTABLE`, `CALCSET <row>, <q1>, <q2>`, `EMBEDCALC`)**: Displays a live `Saturn-Calc` financial worksheet with automatic row/column totals and embeds the formatted table directly into the active `Saturn-WP` document.
- **`Saturn-Base` Relational Mail-Merge (`BASELIST`, `BASEADD`, `MERGE`)**: Merges relational customer records (`<NAME>`, `<COMPANY>`, `<SYSTEM>`) into form documents.
- **Ruler & Document Formatting (`RULER`, `HEADER`, `FOOTER`, `FORMAT`, `PRINT ON`, `EXPORT`)**.
