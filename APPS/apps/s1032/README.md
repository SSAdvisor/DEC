# Software House System 1032 VAX/VMS 4GL & Compressed Bitmap DBMS

**System 1032** is an authentic DEC VAX BASIC recreation of the high-speed Fourth-Generation Language (4GL) and compressed bitmap relational DBMS developed by **Software House, Inc. (Cambridge, MA)** specifically for 32-bit DEC VAX/VMS systems (as the VAX-native successor to PDP-10 `System 1022`), featuring run-length encoded inverted bitmap indexes (`FIND`) that evaluate boolean record selections with zero disk reads.
