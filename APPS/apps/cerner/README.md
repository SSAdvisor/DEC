# Cerner PathNet V3.0 Clinical Laboratory Information System (HNA)

**Cerner PathNet V3.0** is an authentic DEC VAX BASIC recreation of the flagship Healthcare Network Architecture (`HNA`) Clinical Laboratory Information System (`LIS`) developed by **Cerner Corporation (Kansas City, MO)** for DEC VAXcluster hospital environments (1984–1995), supporting specimen barcode accessioning (`ACCESSION`), automated analyzer verification (`VERIFY`), critical panic value alert reporting (`PANIC`), and cumulative patient laboratory charting (`CHART`).
