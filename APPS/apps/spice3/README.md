# VAX SPICE 3D1 / HSPICE Electronic Circuit Simulator

**VAX SPICE 3D1 / HSPICE** is an authentic DEC VAX BASIC recreation of the classic Berkeley SPICE3 and Meta-Software HSPICE electronic circuit simulation environment for DEC VAX/VMS systems, supporting netlist management (`NETLIST`), DC operating point analysis (`OP`), transient time-domain waveform simulation (`TRAN`), and AC small-signal Bode frequency response (`AC`).
