# MINITAB-11 (V82.1)

Interactive Statistical Worksheet for RSTS/E by Penn State University & Minitab Inc. (`minitab`, `mtab`).

## Commands
- `SAMPLE` — Load 6-row industrial process dataset into columns `C1:YIELD`, `C2:TEMP`, `C3:PRESS`
- `PRINT` / `LIST` — Display worksheet columns and rows
- `DESCRIBE` — Compute `N`, `MEAN`, `SUM`, `MIN`, `MAX`, and `RANGE` for each column
- `HISTOGRAM` — Render ASCII bar histogram of `C1:YIELD`
- `PLOT` — Display bivariate scatter summary `C1:YIELD` vs `C2:TEMP`
- `REGRESS` — Fit least-squares linear regression of `C1:YIELD` on `C2:TEMP`
- `TTEST` — Perform one-sample t-test summary on `C1:YIELD`
- `ADD`, `SAVE [file]`, `LOAD [file]`, `SHOW`, `CLEAR`, `HELP`, `STOP` / `EXIT`
