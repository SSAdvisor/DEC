# Swanson Analysis Systems ANSYS V4.4 Finite Element Analysis (FEA) Suite

**ANSYS V4.4** is an authentic DEC VAX BASIC recreation of the classic structural and thermal Finite Element Analysis (FEA) suite authored by **Swanson Analysis Systems, Inc. (Houston, PA)** for DEC VAX/VMS systems, supporting `/PREP7` mesh generation (`PREP7`), `/SOLU` frontal stiffness matrix solving (`SOLVE`), and `/POST1` Von Mises equivalent stress and safety factor postprocessing (`POST1`).
