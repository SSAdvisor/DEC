# National Information Systems (NIS) ACCENT R V11.4 4GL & RDBMS

**ACCENT R V11.4** is an authentic DEC BASIC-PLUS-2 recreation of the structured Fourth-Generation Language (4GL) and Relational Database Management System authored by **National Information Systems, Inc. (Cupertino, CA)** for DEC PDP-11 RSTS/E and VAX/VMS systems (1979–1990).
