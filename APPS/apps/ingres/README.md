# RTI INGRES V6.2 for VAX/VMS (with QUEL, SQL, VIFRED & ABF)

**RTI INGRES V6.2** is an authentic DEC VAX BASIC recreation of the relational database management system and 4GL development environment created by **Relational Technology, Inc. (RTI / Ingres Corp., Alameda, CA)** for DEC VAX/VMS systems, supporting **QUEL** (`RANGE OF E IS EMP \ RETRIEVE`), **ISQL**, **VIFRED** (Visual Forms Editor), and **ABF** (Application-By-Forms).
