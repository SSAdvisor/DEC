# Oracle RDBMS V6.0 for VAX/VMS (with SQL\*Plus, SQL\*Forms & SQL\*DBA)

**Oracle RDBMS V6.0** is an authentic DEC VAX BASIC recreation of the flagship relational database management system by **Oracle Corporation (Redwood Shores, CA)**, originally developed on DEC PDP-11 and VAX/VMS systems (`ORA_SID`), featuring **SQL\*Plus V3.0**, **SQL\*Forms V3.0** (`INP` trigger validation), and **SQL\*DBA** (`SGA` shared memory and `DBWR`/`LGWR`/`SMON`/`PMON` background process monitoring).
