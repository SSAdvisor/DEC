# Ross Systems MAPS V5.0 Management Accounting & Planning System

**MAPS V5.0** (*MAPS/GL*, *MAPS/MODEL*, *MAPS/AP*, *MAPS/AR*) is an authentic DEC BASIC-PLUS-2 recreation of the corporate responsibility-center accounting and financial modeling suite authored by **Ross Systems, Inc. (Palo Alto, CA)** for DEC PDP-11 RSTS/E and VAX/VMS systems (1976–1990).
