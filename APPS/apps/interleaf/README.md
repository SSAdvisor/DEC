# Interleaf TPS 4.0 — Technical Publishing Software (Interleaf, Inc.)

**Interleaf TPS 4.0** is an authentic DEC VAX BASIC recreation of the high-end workstation technical publishing system developed by **Interleaf, Inc. (Cambridge, MA)** for DEC VAXstation and VAX/VMS environments (1985–1994), featuring hierarchical Desktop/Book/Document catalogs, Component Property Sheets, Micro-Document Vector Frames, Book Pagination/TOC composition, and PostScript Level 1 (`LPPOST`) output.
